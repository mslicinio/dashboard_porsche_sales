## <img src="assets\images\check.png" width="35px"> Sobre
Bootcamp completo parar usar o Excel 365 com Inteligência Artificial aplicada a dados, análise e tomada de decisão.

## <img src="assets\images\alvo.png" width="35px"> Objetivos
- Conceitos Fundamentais do Excel: incluindo o domínio de tabelas, formulas e dashboards criados na ferramenta;  
- Entender como funcionam Machine Learning, LLMs, IA Generativa e agentes para aplicar esses conceitos em produtividade e análise de dados;  
- Criar prompts mais estruturados para interagir com ferramentas de Inteligência Artificial;
- Dominar tabelas, tabelas dinâmicas, formatações condicionais e fórmulas no Excel 365;
- Estruturar processos de ETL com Excel e Power Query para preparar dados para análise;
- Utilizar o Microsoft Copilot e o Claude para apoiar consultas SQL, análise de bases e criação de agentes;
- Desenvolver um Dashboard de Vendas do Xbox como projeto final, transformando dados comerciais em uma visualização clara para acompanhamento de resultados;
